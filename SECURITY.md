# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of ECDAT.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please do not disclose security vulnerabilities through public GitHub issues.

Report suspected vulnerabilities privately through the security reporting mechanism provided by GitHub for this repository.

Include, where possible:

- affected version or commit
- affected component
- reproduction steps
- expected behavior
- observed behavior
- potential security impact
- relevant logs or evidence

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

## Security Scope

ECDAT processes cryptographic discovery and analysis evidence. Security reports concerning:

- authentication or authorization
- sensitive information exposure
- unsafe file handling
- command execution
- dependency vulnerabilities
- API security
- cryptographic implementation flaws
- integrity of analysis results

are particularly relevant.

## Disclosure

After validation and remediation, security issues may be disclosed responsibly with appropriate credit to the reporter unless the reporter requests otherwise.
